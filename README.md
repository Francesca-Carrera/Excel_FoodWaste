# Progetto Excel – Analisi dati per riduzione spreco alimentare.

**Obiettivo**  
Un’azienda che mette in contatto consumatori e attività commerciali per ridurre lo spreco di cibo quotidiano ha fornito un dataset sulle attività aderenti. Questo progetto risponde a 15 domande specifiche del team di marketing.

**Strumenti utilizzati**  
- Formule Excel: `CONTA.NUMERI`, `CONTA.SE`, `CONTA.PIÙ.SE`, `MEDIA.SE`, `MAX.PIÙ.SE`, `CERCA.X`, `UNICI`  
- Tabelle pivot con conteggi, somme, medie e filtri temporali (es. età proprietari alla data del test).
- Tecniche di analisi: ricerca errori ortografici (es. "Molano"), aggregazioni, confronti tra gruppi (es. media kg salvati con/senza promozioni social).

**Struttura del file**  
- `Presentazione` – introduzione al progetto.
- `Test` – elenco delle domande, risposte e processo in breve.
- `RawData` – dataset originale.
- `Operative` – dati arricchiti e formule chiave.
- `Pivot` – tabelle pivot utilizzate per le analisi.
